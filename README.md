# StageStrip

Боковая полоска с миниатюрами недавних окон для macOS. Берёт от системного «Постановщика» только полоску: окна не группируются и остаются там, где вы их оставили.

## Возможности

- **Полоска на каждом экране:** слева, справа или выключена, отдельно для каждого экрана.
- **Плитки недавних окон:** клик по плитке открывает окно. На плитке — миниатюра и значок приложения.
- **Настраиваемый вид:** от 1 до 10 плиток (по умолчанию 5) и прозрачность до 80%.
- **Сворачивание в плитку:** Cmd+M и жёлтая кнопка отправляют окно на полоску с анимацией, а не в Dock.
- **Не мешает работе:** если окно заходит на край экрана с полоской, она уезжает и выезжает, когда мышь подходит к этому краю. На полноэкранных окнах она скрыта, а при открытии Центра уведомлений и показе рабочего стола убирается.
- **Окна с запретом захвата** (например, KeePassXC) показываются карточкой с заголовком вместо миниатюры.

Приложение не обращается к сети: миниатюры остаются на вашем компьютере.

## Установка

Нужна macOS 15 или новее, Apple Silicon или Intel.

1. Скачайте архив из [последнего релиза](https://github.com/Vyazan/stagestrip/releases/latest), распакуйте его и перенесите `StageStrip.app` в `~/Applications`.
2. Приложение не заверено Apple, поэтому снимите карантин в Терминале:
   ```sh
   xattr -dr com.apple.quarantine ~/Applications/StageStrip.app
   ```
3. Откройте приложение и выдайте два разрешения в настройках macOS:
   - **Универсальный доступ:** чтобы находить и двигать окна и перехватывать сворачивание.
   - **Запись экрана:** чтобы снимать миниатюры.
4. Выключите системный «Постановщик»: Системные настройки → Рабочий стол и Dock.

При обновлении разрешения придётся выдать заново: у готовой сборки нет постоянной подписи. Если они включены, но приложение их не видит, сбросьте их и перезапустите его:

```sh
tccutil reset Accessibility local.stagestrip
tccutil reset ScreenCapture local.stagestrip
```

## Настройка

Всё находится в меню значка в строке меню: сторона полоски для каждого экрана, количество и прозрачность плиток, автозапуск.

Значок можно скрыть пунктом меню. Чтобы вернуть его, откройте StageStrip ещё раз.

При выходе из приложения свёрнутые в плитки окна возвращаются на экран.

## Сборка из исходников

```sh
./build.sh
```

Нужны инструменты командной строки Xcode. Приложение появится в `~/Applications/StageStrip.app`. Чтобы разрешения не сбрасывались при каждой пересборке, заведите в связке ключей самоподписанный сертификат для подписи кода с именем, начинающимся на `Local Code Signing`: скрипт найдёт его сам.

## Автозапуск через launchd

Вместо пункта меню можно использовать LaunchAgent, который ещё и перезапускает приложение при сбое:

```sh
sed "s|__HOME__|$HOME|" local.stagestrip.plist > ~/Library/LaunchAgents/local.stagestrip.plist
launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/local.stagestrip.plist
```

Отключение:

```sh
launchctl bootout gui/$(id -u) ~/Library/LaunchAgents/local.stagestrip.plist
rm ~/Library/LaunchAgents/local.stagestrip.plist
```
